# Portfolio reflection draft

## Why did you choose this project?

I chose Virus Spread Lab because it gave me a practical way to build a C++ program around a clear set of rules and visible outcomes. The project let me work with simulation state over time and turn that logic into an interactive console experience.

## What skills and technologies did you use?

I used C++ to organize the simulation around Person, VirusProfile, and Simulation classes. I worked with input validation, state changes, daily counts, and reproducible runs. Visual Studio was my development environment, and Git and GitHub helped me keep the project organized.

## What challenge did you face, and how did you address it?

One challenge was keeping the simulation’s person states and daily updates consistent as the run progressed. Breaking responsibilities into classes made the logic easier to follow, and checking user input helped keep invalid menu choices from disrupting a run.

## What would you improve next?

I would add more scenario options and clearer ways to compare results across multiple runs. I would also expand the visual summary so changes in susceptible, infected, and recovered counts are easier to compare over time.
