# Portfolio site

This repository contains the public portfolio site for Jason Brandow.

## Site files

- index.html — portfolio home page
- styles.css — shared responsive layout and styles
- demo.html — interactive browser preview of the Virus Spread Lab concept
- resume.html — resume page

## Project source

The original C++ course project is in [COS1-Project](https://github.com/jasonbrandow9-pixel/COS1-Project). The browser preview is an illustrative model and is separate from the C++ console program.

## Publishing

The GitHub Pages site uses the main branch and the repository root. The public address is https://jasonbrandow9-pixel.github.io/.

## Updating the site

Make edits on dev, review them, and merge finished changes into main. GitHub Pages publishes the root index.html from main.
