SELECTED PROJECT

C++ · CONSOLE APPLICATION · COURSE PROJECT

Virus Spread Lab

A small educational simulation that places people on a grid and advances one day at a time. It reports susceptible, infected, recovered, and new-infection counts.

What it includes

  • Three illustrative transmission and recovery profiles
  • A grid view, daily report, Quick Run, and profile comparison
  • Repeatable seeds, optional report export, and validated menus

One lesson from the work

A replay-loop change exposed a scope error: settings were used outside the loop where they were created. I moved the related work into the right scope and improved numeric input handling.

Tools: C++, Visual Studio, Git, GitHub
